# Задача: система учёта заказов цветочного магазина

Напиши консольную программу на Python, которая хранит каталог цветов, принимает заказы и учитывает остатки на складе. Данные должны сохраняться в файл `shop.json`, чтобы после перезапуска программы каталог и заказы не терялись.

## Каталог

У каждого товара должны быть:

- уникальный ID;
- название;
- цена за штуку;
- остаток на складе.

При первом запуске создай несколько товаров, например:

```text
1 — Красная роза, 300 ₽, остаток 50
2 — Белая роза, 320 ₽, остаток 30
3 — Хризантема, 250 ₽, остаток 40
```

## Меню программы

Пользователь может выбрать действие:

1. Показать каталог.
2. Создать заказ.
3. Показать все заказы.
4. Изменить статус заказа.
5. Показать отчёт.
6. Завершить программу.

## Создание заказа

Пользователь вводит товары и их количество. Программа должна:

- проверить, что товар существует;
- проверить, что количество — положительное целое число;
- проверить, что товара достаточно на складе;
- рассчитать стоимость каждой позиции и итоговую сумму;
- уменьшить остаток товара;
- присвоить заказу уникальный номер.

Применяй скидку ко всему заказу:

- от **5 000 ₽** — скидка **5%**;
- от **10 000 ₽** — скидка **10%**;
- если сумма меньше 5 000 ₽ — без скидки.

Применяется только одна скидка — наибольшая подходящая.

## Статусы заказа

У заказа должен быть один из статусов:

- `Новый`;
- `Выполнен`;
- `Отменён`.

Пользователь может изменить статус. Если заказ отменяется, товары из него нужно вернуть на склад. Повторная отмена или повторное выполнение заказа не должны повторно менять остатки и отчёты.

## Отчёт

Покажи:

- общее количество заказов;
- количество новых, выполненных и отменённых заказов;
- сумму выручки по выполненным заказам;
- товар с наибольшим количеством проданных штук;
- текущие остатки товаров.

## Технические требования

- Раздели программу на функции: например, `показать_каталог()`, `создать_заказ()`, `изменить_статус()`, `показать_отчёт()`.
- Сохраняй и загружай данные из JSON-файла.
- Обрабатывай неверный ввод и отсутствующий файл без аварийного завершения программы.
- Не используй сторонние библиотеки.
